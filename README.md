# chestnij-garazh-agent

Разбор звонков автосервиса «Честный Гараж» (amoCRM + расшифровки Войси + Kimi).

Репозиторий: https://github.com/Plyotka/chestnij-garazh-agent (бывший `chg-razbor`, переименован 28.10.2026).

Запускается GitHub Actions по расписанию в рабочем окне 08:30–18:30 МСК
(сетка :27/:57 — компенсация возможных задержек GitHub cron).
Код — тот же, что в облачной функции Яндекса `chg-razbor` (папка
`yandex-cloud` в рабочем пространстве); Яндекс-вариант остался как
горячий резерв на случай возврата.

## Правила (зафиксированы 27–28.10.2026)

- Категория 1 (нет сути) и пропущенные без контакта → Бадри, задача на 18:00.
- Категория 2 (теплый) → Константин, «Тёплые», задача на завтра 10:00.
- Категория 3 (договорились о приезде) → Константин, «приедет», задача ко времени.
- Категория 4 (уже приехал) → задачу не ставить, ответственного не менять; если
  сделка ещё не в «приехал» — поднять её туда (уточнение правила 28.10).
- Категория 5 (отказ) → «Закрыто не реализовано», причина «Не наш профиль».
- ШАГ 0 (добавлен 28.10): в начале каждого прогона переносить открытые
  просроченные задачи — сделка в 142/143 → закрыть задачу, иначе перенос
  на сегодня 18:00 (прошло — на завтра 10:00). Текст/ответственного/связь не менять.
- Лоток «Неразобранное» (unsorted, добавлено 28.10): пропущенные из телефонии
  принимаются в воронку (accept с пустым телом → «Первичный»), короткое имя
  «Пропущенный звонок +7…», контакт с телефоном, далее стандартный поток
  пропущенных (Бадри + задача + маркер). Чаты и формы лотка не трогаем.
- Этап сделки никогда не понижается; статусы 142/143 не трогаются;
  заметки не удаляются; суммы не меняются; без эмодзи.

## Статус внешних зависимостей

- **Транскрибация Войси — приостановлена с 31.10.2026 (ждём оплаты).** Новые звонки
  без расшифровки корректно откладываются разбором; заметка-флаг менеджеру через 6 ч
  («проверьте запись вручную») в это время — ШТАТНОЕ поведение, а не сбой. После оплаты
  транскрибация и разбор возобновятся автоматически. Пропущенные/лоток/MAX/починка
  телефонов не зависят от Войси и работают.

## Секреты (Settings → Secrets and variables → Actions)

- `AMO_TOKEN` — Bearer amoCRM
- `MOONSHOT_API_KEY` — Kimi API (модель kimi-k2.6, только temperature=1)

## Ручной прогон

Actions → chg-razbor → Run workflow → `dry_run: true` — полный прогон
на чтение без записи в amo (проверка связки и LLM).

## Локальный запуск

```bash
AMO_TOKEN=... MOONSHOT_API_KEY=... DRY_RUN=true python3 razbor.py
```
